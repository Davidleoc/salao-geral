# MeuAgendamento — SaaS de agendamento

Agenda online e gestão (clientes, custos e lucro) para negócios com hora marcada:
salões de beleza, barbearias, manicures, estética, estúdios e outros.

- **Onde fica cada coisa, como mudar textos, regras do projeto:** veja [ARQUITETURA.md](ARQUITETURA.md)
- **Rodar:** `venv\Scripts\python.exe -m uvicorn app.main:app --port 9080 --reload`
- **Testar:** `venv\Scripts\python.exe -m pytest -q`
